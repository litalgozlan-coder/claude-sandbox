# claude-sandbox

## רוקדים וזזים 🎵

משחק ריקוד וכושר בדפדפן, בסגנון Dance Dance Revolution. חצים עולים על המסך בקצב השיר, ודורכים לכיוון שלהם. מצלמת הרשת מזהה את כפות הרגליים בעזרת MediaPipe Pose.

### איך משחקים
1. מורידים את `index.html` ופותחים אותו ב-Chrome או ב-Edge במחשב. צריך אינטרנט בפעם הראשונה כדי לטעון את מודל הזיהוי.
2. לוחצים "הפעלת מצלמה" ומאשרים גישה.
3. מניחים את המחשב נמוך, ועומדים 2.5–3 מטר ממנו, כך שרואים את כל הגוף כולל כפות הרגליים.
4. עומדים בלי לזוז כמה שניות לכיול, בוחרים שיר ורמת קושי, ומתחילים.

| חץ | תנועה |
|---|---|
| ⬅️ | צעד הצידה שמאלה |
| ➡️ | צעד הצידה ימינה |
| ⬆️ | צעד קדימה, לכיוון המסך |
| ⬇️ | צעד אחורה |

אחרי כל צעד חוזרים לאמצע.

- 3 שירים מובנים (100, 118 ו-132 פעימות לדקה), ו-3 רמות קושי.
- אפשר להעלות קובץ MP3 משלך. המשחק מזהה את הקצב ובונה ממנו חצים.
- בהגדרות: גודל הצעד הנדרש, תיקון עיכוב המצלמה ומהירות החצים.
- אם זיהוי השלד לא נטען, המשחק עובר לזיהוי תנועה באזורים. אפשר תמיד לשחק גם עם מקשי החצים.
- התמונה מהמצלמה מעובדת רק במחשב ולא נשלחת לשום מקום.
