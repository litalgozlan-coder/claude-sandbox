# claude-sandbox
TEST CLAUDE

## ביט ראשון – משחק היפ־הופ למתחילים

`dance/index.html` – משחק ריקוד שנפתח בדפדפן של הנייד ומשתמש במצלמה הקדמית לזיהוי תנוחות הגוף (MediaPipe, רץ בתוך המכשיר).
אחרי הפעלת GitHub Pages הכתובת תהיה: https://litalgozlan-coder.github.io/claude-sandbox/dance/

## קיקבוקס בקצב – אימון קיקבוקס עם המצלמה

`kickbox/` – אותו מנוע של משחק הריקוד, לקיקבוקס: ג׳אב, קרוס, הוקים, מכות לגוף, ברכיים, בעיטה קדמית ובעיטות סיבוביות, כל מכה בדיוק על הביט של השיר.
שלושה שלבים (אגרופים, בעיטות, קומבינציות), 12 קומבינציות מלוחם אמיתי בלכידת תנועה (Mixamo), מצב לימוד ומצב אימון, פלייליסטים של אימון מספוטיפיי.
הכתובת: https://litalgozlan-coder.github.io/claude-sandbox/kickbox/

- `dance/tools/compose_kickbox.js` בונה את הקומבינציות ממכות בודדות (אחרי `retarget.js`), כך שכל מכה נוחתת על ספירה.
- הניקוד בקיקבוקס מסתכל גם על קיצור הזרוע מול המצלמה (אגרוף שנשלח אל הנייד נראה קצר) ועל גובה הברך, כי זווית הזרוע לבדה לא מבדילה בין ג׳אב לגארד.
